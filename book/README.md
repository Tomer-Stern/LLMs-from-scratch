# Book & Companion Resources

`Build-a-large-language-models.pdf` — local copy of *Build a Large Language Model (From Scratch)* by Sebastian Raschka (Manning). It is gitignored because the book is copyrighted.

All chapter code, appendices, exercise solutions (appendix C), and bonus material from [sebastianraschka.com/llms-from-scratch](https://sebastianraschka.com/llms-from-scratch/) already live in this repo (`ch01`–`ch07`, `appendix-A`–`appendix-E`). The resources below are hosted externally:
